# Courage Ballack – Ignite Studios page

Static site: `index.html`, `privacy.html`, `terms.html`, `cookies.html` and `media/` (five MP4s). No build step.

1. Push this folder to GitHub.
2. In Vercel: Add New > Project > import it. Framework preset: Other. Leave build settings empty.

Optional: set `FORM_ENDPOINT` (Formspree) and `CHECKOUT_URL` near the bottom of `index.html`.
